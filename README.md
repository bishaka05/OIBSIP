# OIBSIP_DataScience_Task1

**Iris Flower Classification using Machine Learning:** Developed a Machine Learning model to classify Iris flowers into different species using sepal and petal measurements. Included data preprocessing, visualization, model training, and performance evaluation. 🌸📊

**Tools & Technologies:**

1. Python
2. Pandas
3. NumPy
4. Matplotlib
5. Seaborn
6. Scikit-learn

**Steps Performed:**

1.Loaded and explored the Iris dataset.
2.Performed data cleaning and preprocessing.
3.Conducted Exploratory Data Analysis (EDA).
4.Created visualizations to understand feature relationships.
5.Trained and evaluated a Machine Learning classification model.
6.Predicted Iris flower species based on flower measurements.

**Outcome:** Successfully developed a Machine Learning model that accurately classifies Iris flowers into Setosa, Versicolor, and Virginica species based on their sepal and petal characteristics.
